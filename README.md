A collection of daily Advent of Code implementations. Most files are standalone JavaScript programs; Day 24 also includes a Python solution using SymPy.

## Quick start

```sh
git clone https://github.com/pagyew/AoC-2023.git
cd AoC-2023
node 1.js
```

The scripts do not share a single input format or runner. Some contain embedded example or puzzle data. Check the selected file and replace its input before using it with your own puzzle data. These are learning implementations, not a claim that every puzzle has a verified solution.

### Day 24 in Python

Use Python 3 and install SymPy in a virtual environment:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install sympy
.venv/bin/python 24.py 24i.txt
```

Save your own Day 24 input as `24i.txt` first. The Python script reads the path from its first argument.
